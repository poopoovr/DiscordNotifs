# DiscordNotifs
Gorilla Tag mod that imports your discord notifications into the game!

Steps: 
1: Download the dll from Releases (Recommended) 
2: Open the game once with the mod in your plugins
3: Go to bepinex/config
4: Open "com.poopoovr.discordnotifs.cfg" and enter your discord token after the "="
5: Change the preferred hand (Left Or Right) (Optional)
6: Open game after setup and enjoy!

## PC and VR supported!
